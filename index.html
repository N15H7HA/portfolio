    Problem Statement

    Reliable MRI brain-tumor detection demands both high accuracy and clinical interpretability, yet limited medical datasets and class imbalance make robust, trustworthy models hard to train.

    Architecture

    MRI input → EfficientNet-B3 backbone → custom classification head → Focal Loss with label smoothing → Grad-CAM++ localisation → interpretable heatmap output.

    Key Features
    • Binary MRI brain-tumor classifier on EfficientNet-B3 with a custom classification head, reaching 98.03% test accuracy and AUC 0.9994 on a 305-image held-out test set
    • Focal Loss with label smoothing, MixUp augmentation, and CosineAnnealingWarmRestarts to handle class imbalance and improve generalisation on a limited medical dataset
    • Grad-CAM++ for pixel-level tumor localisation, producing clinically interpretable heatmaps to support radiologist trust in AI predictions
    • Zero false positives, a 2.84% false-negative rate across 305 held-out test images, Cohen’s Kappa of 0.97, and F2 score of 0.99
    Results

    Outperformed ResNet50, DenseNet201, and Inception baselines while delivering explainable, clinically actionable predictions.

    Problem Statement

    Cross-camera person re-identification must match individuals across viewpoints and lighting, where rigid manual thresholds on deep features generalise poorly.

    Architecture

    Person image → part-based split (head, torso, legs) → ResNet-50 embeddings + HSV histograms + HOG descriptors → weighted feature fusion → GMM-calibrated Type-1 Mamdani fuzzy inference → ReID decision.

    Key Features
    • Type-1 Mamdani fuzzy inference system integrated with deep-learning features for cross-camera surveillance ReID
    • Part-based pipeline dividing person images into head, torso, and leg regions; ResNet-50 embeddings, HSV color histograms, and HOG descriptors
    • Weighted feature-fusion framework with fuzzy membership functions calibrated via Gaussian Mixture Models (GMM) to eliminate manual threshold tuning
    • SMOTE-based class balancing and decision thresholds optimised with a combined Youden-J and Maximum-F1 strategy
    Results

    Evaluated on the PETS 2009 benchmark: 99.25% Accuracy, 99.27% ROC-AUC, 98.75% mAP, and 100% Rank-1 Accuracy.
